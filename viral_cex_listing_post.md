## Algorithm Optimization Breakdown

Based on X's recommendation algorithm source code:

### Primary Ranking Signals:

1. **favorite_score (Likes)** ← Highest weight
   - Hook: $ comparison (relatable)
   - FOMO: "First CEX to list gets..."
   - Meme-able: "It's an onboarding event"

2. **reply_score** ← Second highest weight
   - Multiple CEX tags = reply wars potential
   - Question at end: "Which exchange moves first?"
   - Controversial claim invites debate

3. **retweet_score** ← Direct amplification
   - Explicit CTA: "RT if..."
   - Shareable business insight
   - Not too long (repost friction)

4. **quote_score** ← Drives discussion
   - "It's not a listing. It's an onboarding event." ← quotable
   - "$0/user acquisition" ← meme-able stat
   - Business framing = professional quote-tweets

5. **dwell_time** ← Continuous metric
   - Dense information (numbers, bullets)
   - But short enough for mobile (< 280 chars ideal)
   - Scannable format (bullets, line breaks)

### Secondary Signals:

6. **share_score / share_via_dm_score**
   - Business-relevant = gets shared in work chats
   - CEX employees will DM this to BD teams

7. **profile_click_score**
   - Multiple CEX tags = users checking if CEX replied
   - Tag checking = profile visits

### Negative Signal Avoidance:

- ✅ No spam patterns (authentic business pitch)
- ✅ No excessive tags (9 CEXes = reasonable for this context)
- ✅ No misleading claims (conservative math)
- ✅ Won't trigger block/mute (professional tone)

### Author Diversity Consideration:

- Your first post on this topic gets **full weight**
- Second similar post gets `(1-floor) × decay^position + floor`
- Don't post multiple versions in quick succession
- Space out attempts by 24-48 hours if first doesn't land
